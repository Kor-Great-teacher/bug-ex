# 꼬마 파브르 곤충 리그 (bug-ex)

교실용 멀티플레이 퀴즈 대결 게임입니다. 파브르 곤충기처럼 다양한 **귀여운 곤충 캐릭터**를 퀴즈로 모으고, 코인으로 키워서, 친구들과 **실시간으로 대결**해요. 함께 하기는 최대 4명이에요.

```
대기실 → ① 곤충 채집 퀴즈 7문제 → ② 코인 퀴즈 13문제 → ③ 연구소 2분 → ④ 1차전 → 연구소 1분 → 2차전 … → 6차전
       → 최종 순위 · 명예의 전당 → [처음부터 다시 시작] 또는 [곤충 키우기]
```

- **화면**: PC · 태블릿 · 휴대폰 모두 **가로 16:9** 한 화면(1024×576 판을 화면 크기에 맞춰 늘리거나 줄여요). 세로로 든 휴대폰 · 태블릿은 판을 90도 돌려 보여 주고, 시작할 때 전체 화면 + 가로 고정을 시도해요. 위아래 스크롤 대신, 내용이 많은 곳(연구소 2쪽 · 틀린 문제 · 도움말 · 관리자 설정 · 곤충 목록)은 **좌우로 넘겨요** (버튼 · 밀기 · 마우스 휠).

- **실시간 대결 서버**: Node.js + Express + Socket.IO (`server.js`). [Render](https://render.com)에 그대로 올릴 수 있어요 (`render.yaml`).
- **혼자 연습**: 서버 없이도 AI 곤충 2마리와 대결할 수 있어요 (`public/index.html`을 그냥 열어도 됨).
- **곤충 키우기**: 3마리를 골라 퀴즈로 계속 키우고, 키운 곤충은 다음 게임에서 기본 곤충으로 함께 출발해요.
- 시작 화면 · 별명 · 구글 시트 문항 · 명예의 전당 · 관리자 전역 설정은 [ant-ex(피자 수호대)](https://github.com/Kor-Great-teacher/ant-ex)와 같은 방식이에요 (`GameKit`).

## Render에 배포하기

1. [render.com](https://render.com)에 GitHub 계정으로 로그인
2. **New → Blueprint** → 이 저장소(`bug-ex`) 선택 → `render.yaml` 설정대로 웹 서비스가 만들어져요
   - 직접 만들 때: **New → Web Service** → 저장소 선택 → Runtime `Node`, Build `npm install`, Start `npm start`, Health Check Path `/healthz`
3. 배포가 끝나면 `https://bug-ex-xxxx.onrender.com` 같은 주소가 생겨요. 학생들에게 이 주소를 알려 주세요.

- Render 무료 요금제는 15분 동안 아무도 접속하지 않으면 잠들어요. 수업 전에 한 번 열어 두면(약 30초~1분) 깨어나요.
- 저장소에 커밋하면 Render가 자동으로 다시 배포해요 (`autoDeploy: true`).
- 내 컴퓨터에서 실행: `npm install` → `npm start` → <http://localhost:3000>

## 시작 화면 · 게임 방식 · 명예의 전당

첫 화면에서 **별명**(자동 생성 `도전자12345`, 직접 수정 가능), **방식**, **난이도**를 고르고 시작해요.

- **함께 하기 (최대 4명, 실시간)**: 시작하면 **입장 코드** 칸이 나와요.
  - **입장 코드를 넣으면 코드 방**: 같은 코드를 넣은 친구들과 대기실에 모여요. 화면에 **[기다리기]** 와 **[30초 기다린 후에 AI와 자동 대결]** 두 버튼이 나와요.
    - [기다리기] → 2명 이상 모이면 **[지금 시작하기]** 가 켜지고, 입장한 친구가 **모두** 누르면 바로 시작해요. 빈자리는 비워 둔 채 **2명 · 3명 · 4명** 그대로 경기해요.
    - [30초 기다린 후에 AI와 자동 대결] → 30초가 지나면 빈자리를 AI 곤충이 채워 4명으로 시작해요.
  - **코드 없이 [시작하기] → 자동 매칭**: 아무나 모여서 4명이 되면 바로, 30초가 지나면 AI가 빈자리를 채워 시작해요.
  - 퀴즈부터 대결까지 서버가 모두 함께 진행해요. 문제는 방장(먼저 들어온 학생) 컴퓨터가 만들어 보내요 (구글 시트 문제·선생님 문제도 그대로).
  - 중간에 나간 학생의 곤충은 AI가 대신 대결해요.
- **혼자 연습**: AI 곤충 2마리와 대결해요. 서버가 없어도 돼요. 연구소 시간 제한은 없어요.
- **난이도**: AI 곤충의 세기 (쉬움 · 보통 · 어려움). AI는 사람 참가자의 업그레이드 수준에 맞춰 능력치를 받아요.
- **명예의 전당**: 마지막 대결이 끝나면 점수가 자동으로 기록되고, `현재 게임 랭킹` / `전체 랭킹` 버튼으로 순위를 봐요. 랭킹 옆 `🥇3`은 1등 횟수예요.

### 주소(URL) 파라미터

| 파라미터 | 의미 | 예 |
| --- | --- | --- |
| `room` | 입장 코드 미리 넣기 | `?room=1234` |
| `gamemode` | `free` 는 혼자 연습, 숫자는 친구와 대결 + 채집 문제 수 | `?gamemode=free` |
| `goal` | 곤충 채집 문제 수 | `?goal=5` |
| `difficulty` | 난이도 미리 선택 (`easy` / `normal` / `hard`) | `?difficulty=hard` |
| `sheet` + `gid` | 구글 시트 문제로 출제 (시트 문제만 나와요) | `?sheet=12uL…ew&gid=1499192131` |
| `rank` | 기록용 웹앱 주소 변경 | `?rank=https://script.google.com/…/exec` |
| `server` | 다른 곳에 있는 대결 서버에 연결 | `?server=https://bug-ex.onrender.com` |

여러 개는 `&` 로 이어요: `?room=1234&sheet=…&gid=…`
채집 문제 수 우선순위: 주소의 `gamemode`/`goal` → 시트 SETTING `gameModeGoal` → 관리자 설정 → 기본 7

### 구글 시트 문제 형식

시트는 **공유 > 링크가 있는 모든 사용자 > 뷰어** 로 열어 두세요. (ant-ex와 같아요)

| A (Type) | B (Key/ID) | C (Value/Text) | D~G (Opt1~4) | H (Answer) | I (Explanation) |
| --- | --- | --- | --- | --- | --- |
| `SETTING` | `subtitle` · `gameModeGoal` 등 | 값 | | | |
| `multiple` | 번호 | 문제 | 보기 1~4 | 정답 번호(1~4) | 해설 |
| `ox` | 번호 | 문제 | | `O` / `X` | 해설 |
| `short` | 번호 | 문제 | | 정답 (여러 개는 `\|` 로 구분) | 해설 |

`subtitle` 에 `과학-3학년 1학기-3.동물의 한살이` 처럼 쓰면 첫 화면과 랭킹에 단원이 표시돼요. 해설은 정답·오답 화면에 💡로 보여 줘요.

## 게임 규칙

| 단계 | 내용 |
| --- | --- |
| ① 곤충 채집 (7문제) | (어떤 곤충이든 등급은 확률로 · 같은 곤충은 모은 수 +1) 모두 같은 문제를 실시간으로 풀어요. 먼저 푼 친구는 정답이 공개되지 않은 채 **"참가자가 문제를 푸는 동안 잠시 기다립니다"** 창과 남은 시간 타이머를 봐요. 모두 풀거나 시간이 다 되면 정답 공개. 정답 → 곤충 채집 (일반 55% · 희귀 28% · 영웅 12% · 전설 5%), 이미 있는 곤충이면 능력치 +1. **하나도 못 맞혀도 기본 곤충 1마리**는 받아요. |
| ② 코인 퀴즈 (13문제) | **정답을 맞힌 순서**대로 코인: 4명 1등 20 · 2등 15 · 3등 10 · 4등 5 (3명 15 · 10 · 5, 2명 10 · 5), 틀리면 0. 문제마다 약 2초 동안 이번 문제 코인과 순위, **누적 코인 합계**를 보여 줘요. 혼자 연습은 걸린 시간으로 20 · 15 · 10 · 5. |
| ③ 곤충 연구소 | 처음 **2분**, 대결 사이 **1분**. 코인으로 능력치를 올리고(12 → 18 → 24 …), 조건을 채우면 **등급업**, 출전 곤충을 골라요. [준비 완료]를 모두 누르면 바로 시작, 시간이 끝나면 지금 고른 곤충으로 **자동 출전**. |
| ④ 곤충 대결 (6차전) | 참가자 모두(2~4명)가 10가지 종목 중 무작위 종목으로 겨뤄요. **한 곤충은 2번까지** 출전할 수 있어요 (6차전이면 최소 3마리가 필요해서, 모자라면 기본 곤충을 채워 줘요). 1등 코인 60 · 2등 40 · 3등 25 · 4등 15. |
| 최종 순위 | 대결 점수(1등 = 참가 수 … 꼴등 1점) 합계로 순위. 결과 화면 맨 위에 **[처음부터 다시 시작]** · **[곤충 키우기]**, 맨 아래에 명예의 전당(기록 · 랭킹 버튼). 틀린 문제는 오른쪽 쪽으로 넘겨서 봐요. |

- **점수**: 정답 100 · 새 곤충 일반 50 / 희귀 100 / 영웅 150 / 전설 250 · 업그레이드 10 · 등급업 50(희귀)·75(영웅)·125(전설) · 대결 1등 300 / 2등 150 / 3등 50 / 4등 20

### 곤충 키우기

- 게임이 끝나고 **[곤충 키우기]** 를 누르면 가진 곤충(이전에 키우던 곤충 포함) 중 **3마리**를 골라요. 같은 곤충은 더 센 쪽만 남아요.
- 퀴즈를 맞힐 때마다 코인(기본 20, 관리자 설정)을 받아 업그레이드 · 등급업으로 계속 키워요. 자동으로 저장돼요 (그 브라우저에 저장).
- 시작 화면의 **🌱 곤충 키우기** 링크로 언제든 다시 들어갈 수 있어요.
- 키운 곤충은 다음 게임(함께 하기 · 혼자 연습)에서 **기본 곤충**으로 함께 출발해요 (연구소 카드에 🌱 표시). 경기 중에 더 키운 만큼은 다시 [곤충 키우기]로 고르면 이어서 저장돼요.
- 게임이 끝나면 **틀린 문제 목록**을 보여 줘서 복습할 수 있어요.

### 등급 · 모으기 · 업그레이드 · 등급업

- **등급은 곤충 종류와 상관없이** 채집할 때 확률로 정해져요. 어떤 곤충이든 전설로 나올 수 있어요.
- 같은 곤충을 또 잡으면 **모은 수 +1**(곤충 카드 오른쪽 아래 `×2`, `×3` …)과 능력치 하나 +1. 더 높은 등급으로 잡으면 그 등급으로 바로 올라가요.
- **같은 곤충 모은 수**와 **업그레이드 합계** 두 조건을 채우면 **저절로 1등급** 올라가요 (코인은 들지 않아요). 업그레이드는 그대로 남고, 모은 수는 새 등급에서 1부터 다시 세요.

| 등급 | 채집 확률 | 모든 능력치 보너스 | 업그레이드 한계 (능력치마다) | 다음 등급으로 가는 조건 | 장식 |
| --- | --- | --- | --- | --- | --- |
| 일반 | 55% | +0 | 4단계 | 같은 곤충 ×2 + 업그레이드 합계 6 | 없음 |
| 희귀 | 28% | +2 | 7단계 | 같은 곤충 ×3 + 업그레이드 합계 14 | 반짝이 |
| 영웅 | 12% | +4 | 10단계 | 같은 곤충 ×4 + 업그레이드 합계 24 | 보랏빛 기운 + 도는 별 |
| 전설 | 5% | +6 | 12단계 | (최고 등급) | 후광 + 황금 빛살 + 빛 알갱이 |

- 능력치 = 기본 + 등급 보너스 + 업그레이드(등급 한계까지). 능력치 합: 일반 25~45 · 희귀 35~70 · 영웅 45~95 · 전설 55~115
- 아래 등급을 끝까지 키워도 위 등급의 최고치는 넘지 못해서 등급 차이가 분명해요. 대신 키운 일반 곤충은 갓 잡은 희귀 곤충보다 셀 수 있어요.
- **곤충 키우기**에서도 정답을 맞히면 3번에 1번꼴로 키우는 곤충을 한 마리 더 모아요.
- AI 곤충은 사람 참가자의 능력치 합에 맞춰 등급과 업그레이드를 정해요 (난이도 쉬움 88% · 보통 98% · 어려움 108%).
- 실시간 대결에서는 서버가 등급(0~3)과 업그레이드(등급 한계까지)를 다시 확인해요.
- 퀴즈를 풀면 **3초 뒤 저절로** 다음 문제로 넘어가요 (버튼을 누르면 바로).

그림이 없는 곤충은 아래처럼 캔버스로 그린 캐릭터로 나와요. 머리가 몸보다 큰 만화 캐릭터 비율에, 곤충마다 성격이 얼굴에 드러나요.

대결 중에는 상황에 따라 표정이 바뀌어요 (웃음 · 힘줌 > < 과 땀방울 · 어지러움 소용돌이 눈). 곤충 카드마다 곤충 이야기(한살이, 특징 등)가 적혀 있어요.

### 대결 종목 10가지

## 설정 · 관리자 설정

오른쪽 위 **설정** 버튼(시작 화면에서는 '설정' 링크)을 누르면 설정 창이 열려요.

- **일반**: 게임 난이도(AI 곤충 세기), 배경음악·효과음 소리 크기 (브라우저에 저장)
- 설정 창 맨 아래 **제작자 : 열혈교사 최영환(teacher@happyclass.kr)** 표시를 **5초 안에 10번 이상** 누르면 **관리자 설정** 페이지가 생겨요 (새로 고침 전까지 유지).
  - 게임 환경: 난이도, 곤충 채집 문제 수(7), 코인 퀴즈 문제 수(13), 곤충 키우기 정답 코인(20), 대결 횟수(6, 곤충마다 2번까지 출전), 함께 하기 AI와 자동 대결까지 기다리는 시간(30초), 첫 연구소 시간(2분), 대결 사이 재정비 시간(1분), 소리 크기
  - 대결 종목: 무작위로 나올 종목 고르기 (10가지 중 원하는 것만)
  - 퀴즈: 문항 출처 확인(내장 문제 / 구글 시트), 출제 과목, 문제당 제한 시간, 수학 난이도, 선생님 문제 직접 입력

### 모든 학생에게 적용하기 (전역 설정 `config.json`)

관리자 설정의 **저장**은 그 브라우저에만 적용돼요. 모든 학생에게 같은 설정을 쓰려면 저장소의 `config.json`을 고치세요. 게임은 시작할 때, 서버는 매칭할 때마다 이 파일을 읽어요.

1. 관리자 설정 페이지에서 값을 바꾼 뒤, 맨 아래 **전역 설정 파일 만들기** → **복사**
2. **GitHub에서 config.json 편집 열기** 링크를 열고, 내용을 모두 지운 뒤 붙여 넣기
3. **Commit changes** → Render가 다시 배포되는 2~5분 뒤부터 모든 학생에게 적용

#### 관리자 설정에서 바로 저장하기 (GitHub 토큰)

1. GitHub 로그인 → 오른쪽 위 프로필 → **Settings** → 맨 아래 **Developer settings** → **Personal access tokens** → **Fine-grained tokens** → **Generate new token**
2. 이름(예: `곤충 리그 설정`), 기한(예: 90일)을 정하고 **Repository access**는 **Only select repositories** → `bug-ex` 하나만 고르기
3. **Permissions → Repository permissions → Contents** 를 **Read and write** 로 (다른 권한은 주지 않아요)
4. **Generate token** → 나온 `github_pat_…` 토큰을 관리자 설정의 **GitHub 토큰** 칸에 붙여 넣고 **전역 설정 바로 저장**

- 토큰은 게임 코드나 저장소에 들어가지 않고, 그 브라우저에만 보관돼요. 여럿이 쓰는 컴퓨터에서는 **이 브라우저에 토큰 기억하기**를 끄거나 **토큰 지우기**를 누르세요.
- 적용 순서: 기본값 → `config.json`(전역) → 그 브라우저에만 저장한 관리자 설정 → 학생이 시작 화면에서 고른 난이도
- **실시간 대결**의 종목·기다리는 시간·AI 세기는 서버가 `config.json`을 따라요 (브라우저에만 저장한 값은 혼자 연습에만 적용).
- 담을 수 있는 값: `difficulty`, `subjects`, `timeLimit`, `mathLevel`, `collectCount`, `coinCount`, `coinPerCorrect`, `battleCount`, `matchWait`, `labTime`, `relabTime`, `events`, `custom`
- 함께 하기의 문제 수 · 제한 시간 · 연구소 시간 · 대결 횟수는 **방장**(먼저 들어온 학생) 브라우저의 설정을 따르고, AI 세기 · 종목 · AI 대기 시간은 서버가 `config.json`을 따라요.

- **선생님 문제 직접 입력**: 한 줄에 한 문제씩 `문제 | 정답 | 오답1 | 오답2 | 오답3`

```
곤충의 다리는 몇 개일까요? | 6개 | 4개 | 8개 | 10개
우리 반 담임 선생님의 성은? | 김 | 이 | 박 | 최
```

## 캐릭터 그림 바꾸기

캐릭터는 `public/img/bugs/` 의 그림으로 그려요 (그림이 없는 곤충은 게임 안의 캔버스 그림으로 대신 그려요).

1. 그림을 `art/bugs/` 에 넣어요. **배경 투명 PNG/WebP**, 캐릭터는 **오른쪽을 보는** 모습.
   - 대표 그림: `<곤충>.webp` (카드 · 목록 · 채집 화면, 자세 그림이 없으면 대결에서도 이 그림을 움직여 써요)
   - 자세 그림(선택): `<곤충>_<자세>.png` — `stand · happy · strain · dizzy · run1 run2 · push1 push2 · pull1 pull2 · balance1 balance2 · climb1 climb2 · hang1 hang2 · fly1 fly2 · cheer1 cheer2 · attack1 attack2 · damage1 damage2 · defend1 defend2 · idle1 idle2`
   - `<곤충>`: `ant ladybug bee grasshopper cricket butterfly firefly dragonfly dungbeetle mantis cicada rhino stag swallowtail`
2. 자세 모음 그림(포즈 시트, 사슴벌레 시트와 같은 4줄 배치)은 잘라서 넣을 수 있어요: `python3 tools/cut_sheet.py art/sheets/<곤충>.png <곤충>`
3. `python3 tools/build_sprites.py` → 투명 테두리를 잘라 360px 이하 WebP 로 줄이고 `public/img/bugs/manifest.json` 을 만들어요. (Pillow · numpy 필요)

- 대결에서는 자세 그림이 있으면 번갈아 보여 주고(달리기 run1↔run2 등), 한 장뿐이면 통통 뛰기 · 기울기 · 흔들기로 움직여요. 기분(땀방울 · 빙글빙글 별 · 반짝이)과 등급 장식(영웅 보랏빛 기운과 도는 별, 전설 후광과 황금 빛살, 반짝이)은 그림 위에 덧그려요.
- 지금 그림: 13종 대표 그림 + 사슴벌레 자세 28장 + 사마귀 자세 32장 (ChatGPT로 만든 그림). 배경이 투명하지 않은 시트(사마귀)는 어두운 배경을 자동으로 지워요. 위 4가지 표정이 두 줄인 시트는 `--double` 을 붙여요.

## 소리

녹음 파일 없이 Web Audio로 만든 소리예요. 오른쪽 위 **효과음 / 배경음악** 버튼으로 따로 켜고 끌 수 있어요.
